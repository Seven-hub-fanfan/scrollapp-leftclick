# 光标主题资源 v1

`CursorThemes.swift` 管理主题目录、语义角色和系统 ID 映射；`CursorSkinStore.swift`
管理应用状态；独立编写的 `CursorService.m` 管理全局注册和恢复。

## 新增皮肤

1. 在本目录加入二进制 plist，顶层包含 `FormatVersion: 1`、`Identifier` 和 `Roles`。
2. `Roles` 的键使用 `CursorRole.rawValue`。每个角色保存：
   - `PointsWide` / `PointsHigh`：逻辑尺寸，首版统一 32 × 32 pt。
   - `HotSpotX` / `HotSpotY`：从图片左上角计算的点击热点，单位 pt。
   - `FrameCount: 1`、`FrameDuration: 0`。
   - `Representations`：透明 PNG Data，前两份为 32 × 32、64 × 64 px，
     后续可按尺寸递增加入 160、320、512、1024 px 高清源图，最多六份。
   - 原图没有对应造型时，可单独写 `RestoreOriginal: true`，不添加其他字段；
     引擎使用初始备份中的该系统光标，并跟随大小设置。切换时不会沿用上一套皮肤。
3. 在 `CursorCatalog.themes` 添加稳定的英文 ID、分类、预览底色和资源名。
4. 在 `Localization.swift` 的中英文表加入名称、介绍。
5. 先检查角色齐全与热点，再验证应用、连续切换、恢复和异常退出。

列表只读取三个 `资源名-arrow/text/link.png` 缩略图；矢量主题仅生成相应缩略图。
所选主题才加载完整角色资源，完整资源缓存最多保留两套。奶蛙的资源和三个缩略图
合计约 571 KiB。

完整角色：`arrow`、`text`、`link`、`grab`、`crosshair`、`horizontal`、`vertical`、
`diagonalRight`、`diagonalLeft`、`unavailable`、`help`、`zoomIn`、`zoomOut`。
奶蛙的新增十字、帮助、放大、缩小状态由现有造型与符号组合生成；斜向缩放由旋转生成。

资源不保存系统 ID。新增皮肤复用同一映射，避免每套素材重复维护私有标识。
`Wait`、`Empty`、忙碌光标和移除项目反馈保留系统行为。首版只支持静态光标。
原始奶蛙与小七资源来自用户附件；公开分发前需要确认素材使用权。引擎为独立实现。

## 生命周期与校验

- 每次应用先校验尺寸、热点、PNG 和帧参数，再验证原始光标可完整写回。
- 备份原始图像和元数据至 `~/Library/Application Support/Scrollapp/Cursors/recovery.plist`。
- 切换皮肤沿用初始备份；成功回读后才保存主题偏好。
- 正常退出、stdin 关闭、主应用被强制结束：辅助进程通过 kqueue 执行恢复。
- 辅助进程被结束：保留恢复日志；主应用会尝试一次自动重连，启动时先恢复日志。
- 登录会话激活、唤醒和显示器变化：事件触发重新应用；没有空闲轮询定时器。
- 存在未能恢复的条目时保留备份，不覆盖它；重复实例通过文件锁拒绝第二个拥有者。

全局能力依赖 macOS 私有接口。当前实机验证平台为 macOS 26.6.2 / Apple Silicon。
其他 macOS 版本和应用自绘光标需要单独验证。

## 大小与立即刷新（2.3.1）

通用页提供 0.5–8.0 倍的鼠标大小滑轨，默认 1.0 倍，步长 0.1。
`cursorScale` 独立于皮肤 ID 保存，恢复系统皮肤时保留大小设置。
原始角色资源保持逻辑尺寸；辅助进程生成缩放后的 1x/2x 图像并同步调整热点。
WindowServer 以 float32 保存热点，缩放结果先量化以保证回读一致。
系统默认的缩放从最初的恢复备份生成，保留原有角色、多帧布局和时长。
退出时恢复最初的图像、大小、热点和全部表示，不修改系统辅助功能的大小偏好。

应用成功后在当前窗口创建新的 `NSCursor` 并立即设置；在 SwiftUI 更新按钮状态后
再设置一次，避免缓存光标等到下一次点击才刷新。拖动时本地反馈立即更新，
全局注册合并到 100 ms 的事件延迟中，没有常驻轮询。
可使用 `--cursor-refresh-log` 临时验证当前 AppKit 光标，默认不记录。

2.3.2 的皮肤目录只保留系统默认和奶蛙，已移除墨黑、薄荷像素及其收藏入口。
原有已选主题若被移除，启动时回到系统默认；大小偏好保持不变。
本机 macOS 26.6.2 已验证奶蛙与系统默认的 3/4/6/8 倍注册和恢复。
8 倍是本版本的应用上限，不代表 macOS 的硬性上限。

## 高清源图（2.3.3）

奶蛙现保留原包的 32/64/160/320 px 版本，按目标物理尺寸选取足够大的源图，
不足时使用最大版本。前台即时光标和全局替换采用同一选择规则。
十字、帮助、放大/缩小和斜向缩放均在对应分辨率生成，不再按数组下标误算尺寸。
源素材最高 320 px，没有附带 4K 母图；8 倍 Retina 输出需要 512 px，
因此仍有 1.6 倍的插值放大。更高品质应加入真正的 512/1024 px 原图，
不能靠把小图保存为 4K 恢复细节。列表继续只加载小缩略图。

## 小七原图修正版（2.3.5）

`xiaoqi` / `Xiaoqi.plist` 保留用户参考拼图中的 11 个造型。
仅裁切与修改透明度；原尺寸资源的所有可见 RGB 像素与参考图对应位置一致。
没有矢量描摹、降色、去噪、重绘或新增细节。2.3.4 的矢量化版本已弃用。
原图未提供放大/缩小造型，这两个角色使用系统原始图像，覆盖全部 13 个语义角色。

参考拼图为 970 × 564 px；裁切后造型为 93–223 px 宽、95–170 px 高。
应用保存 32/64 px 缩略版本和 182–255 px 原尺寸透明画布，共三档；
原尺寸画布仅添加透明边距，不放大原始造型。不同角色的最大画布尺寸不同。
大倍率按实际 PNG 宽度选取原尺寸资源再插值，8 倍 Retina 输出为 512 px，
不代表素材具有 512 px 或 4K 的原生细节。提高大倍率清晰度需要更大的原始素材。

## 小七高清修复（2.3.6）

按用户要求，对参考拼图进行 4 倍插画超分辨率修复，再从修复图重新提取造型。
实际输入尺寸为 970 × 565 px，输出为 3880 × 2260 px；
处理使用 RealESRGAN_x4plus_anime_6B，没有执行矢量描摹。
这版包含修复模型对线条、颜色过渡与纹理的补算，不再宣称与原图逐像素相同。
原图的造型布局、表情、配色和三条黄色动感线已进行视觉对照。

修复母版画布为 728–1020 px，保存在应用之外。应用仅保留
32/64/160/320/512 px 五档透明 PNG，不携带推理模型或整张拼图。
每个造型的修复母版都超过 512 px；8 倍 Retina 的 512 px 输出
从修复母版缩小生成，不再从 182–255 px 小图插值放大。
大小范围和全部点击热点保持不变；放大、缩小继续使用系统原始图标。
已验证 1/2/4/8 倍的 47 个映射回读、热点、连续切换和 43 个系统光标恢复。

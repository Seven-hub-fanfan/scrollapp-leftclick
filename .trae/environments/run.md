# Scrollapp 启动说明

需要 Apple Silicon、macOS 15 及以上和已安装的 Xcode Command Line Tools。
工程使用系统 Swift / Clang 编译，不需要安装第三方依赖。

## skins-preview

[启动动作](run.json)调用工程的 [预览脚本](../../scripts/run_app.sh)。
它在系统临时目录编译独立 bundle ID 的预览应用，并打开光标皮肤窗口。
命令等待应用退出，运行中的预览由 macOS Launch Services 管理。
重新编译后若预览已经运行，请先退出预览再启动，以加载新二进制。

预览跳过开机启动、辅助功能授权请求与全局滚动监听，保留真实的全局光标皮肤功能。
安装版可继续运行。皮肤引擎使用共享的恢复目录及文件锁，同一时刻只允许一个拥有者。

2026-11-13 已验证本工程的预览窗口可见。当前目录为系统默认、奶蛙、小七三套皮肤；
早期四套皮肤版本的收藏、全局应用与恢复按钮曾完成操作验证。
已验证辅助进程被结束后，主应用启动新的辅助进程并恢复持久化的主题。
唤醒、重新登录和多显示器路径已接入事件监听，尚未进行这些场景的实机测试。

正常分发版本使用 [构建脚本](../../scripts/build_app.sh)，默认输出到 `build/Scrollapp.app`。
本地 ad-hoc 签名不是正式分发签名；替换安装版后可能需要重新授予滚动相关的系统权限。
